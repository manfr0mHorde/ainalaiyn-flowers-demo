# Ainalaiyn Flowers — самостоятельный демонстрационный проект

> Неофициальный прототип для обсуждения с владельцем магазина `@ainalaiyn__flowers`. Не является действующим интернет-магазином.

## Проверенные источники
- Instagram: https://www.instagram.com/ainalaiyn__flowers/ — Firecrawl не поддержал прямое скачивание профиля. По поисковой выдаче Firecrawl найдены подписи к публикациям об Астане, букетах, вариантах оформления и доставке; детали требуют подтверждения владельцем.
- Ссылка 2GIS, переданная для анализа: https://go.2gis.com/ivkxQx — при проверке Firecrawl направила на страницу 404. Адрес не подтверждён.
- **Все букеты в демонстрации — авторские векторные иллюстрации; все цены условные.** Иллюстрации созданы специально для этого проекта (`assets/*.svg`). Они не являются фотографиями продукции магазина.

## Сценарии

**Покупатель:** мобильная витрина → фильтры → букет → корзина → имя, телефон, номер для Kaspi, получение, дата/время, адрес и пожелания → сводка заказа → копирование текста или открытие WhatsApp с подготовленным сообщением, если задан тестовый номер в настройках.

**Флорист (демо):** переключение через «Кабинет флориста», добавление букета и фото, редактирование, «Продан», копирование карточки, локальный просмотр подготовленных заявок и демонстрационной статистики, настройки WhatsApp.

## Ограничения демоверсии

- Без базы данных, сервера и настоящей авторизации. Все данные хранятся в `localStorage` только на устройстве.
- **Кабинет не защищён паролем** и недопустим для производственной работы.
- Изменения продавца не распространяются на покупателей с других устройств. Это концепт для демонстрации.
- Настоящий номер магазина по умолчанию не задан. Нельзя отправлять тестовые заявки на номер магазина без разрешения владельца.
- WhatsApp `wa.me` только открывает подготовленный текст; клиент нажимает «Отправить» самостоятельно. Неизвестно, был ли заказ получен или оплачен.
- Сайт не создаёт удалённые счета Kaspi и не принимает платежи.
- Статистика учитывает подготовленные **локальные демо-заявки**, не реальные продажи.
- Не используйте в тестах реальные персональные данные.

## Публикация в GitHub Pages

1. Создайте **новый отдельный публичный** репозиторий, например `ainalaiyn-flowers-demo`.
2. Скопируйте в его **корень** `index.html`, `style.css`, `app.js`, `.nojekyll`, папку `assets` и README.
3. В `Settings → Pages` выберите `Deploy from a branch → main → /(root)`.
4. Ожидаемый адрес: `https://manfr0mhorde.github.io/ainalaiyn-flowers-demo/` (после успешного развёртывания).

В исходниках используются относительные пути `./`, поэтому сайт готов к размещению по адресу проекта GitHub Pages. Домен и VPS не нужны для демо.

## Что понадобится для реального бизнеса

Авторизация, централизованная база товаров и изображений, защита пользовательских данных, проверенные контакты, согласованные цены и ассортимент, условия доставки, реальная обработка заказов и отдельно подтверждаемая статистика оплат. Возможный стек: FastAPI + PostgreSQL / SQLite на сервере в РК; WhatsApp Business API не нужен для обычной ссылки `wa.me`.

## Разработка

Запуск локально:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`.

SVG-иллюстрации можно пересоздать скриптом `generate_art.py` (Python 3, без внешних зависимостей).
